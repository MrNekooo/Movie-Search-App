# 🎬 Movie Search App

A simple React movie search application built with the OMDb API.

## Features

* Search movies by title
* Display movie posters, titles, and release years
* Loading state while fetching data
* Error handling for invalid searches
* Search using button click or Enter key
* Responsive movie grid layout

## Technologies Used

* React
* JavaScript (ES6+)
* Tailwind CSS
* OMDb API
